# TaskFlow

A lightweight project and task management application.

TaskFlow lets a user sign in, organise work into projects, and track the tasks
inside each project through a simple `TODO -> IN_PROGRESS -> DONE` workflow.

## Status

Early development. The React client is being built out first, with a Python
API to follow.

## Getting started

```bash
npm install
npm start
```

The app runs on http://localhost:3000.
